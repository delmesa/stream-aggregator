# Streaming Aggregator

If you have been afflicted with the curse of liking a wide variety of unpopular/underground music, you probably know the struggle of being spread between several streaming platforms. Or maybe everything you like _is_ on YouTube, but you have a bunch of small playlists that you want to shuffle together, and you're tired of maintaining a mega playlist that contains everything you've ever loved.

This app aims to alleviate those pains by providing a client that pulls together individual playlists from multiple streaming services and allows you to mix them up however you so choose.
